# Как навык вызывает свой скрипт

Этот файл читается инструментом Read как есть, поэтому переменная ниже видна в исходном виде. В SKILL.md её же Claude Code заменяет
настоящей папкой навыка при загрузке (проверено 2026-10-12 в главной сессии и у подагентов, Claude Code 2.1.294, Windows 11).

Пиши в SKILL.md так:

```
python "${CLAUDE_SKILL_DIR}/scripts/x.py" аргументы
```

- Кавычки нужны: в пути к кэшу могут быть пробелы.
- Интерпретатор пишется явно (`python`, не голый путь к скрипту и не `python3`: на Windows `python3` бывает заглушкой Microsoft Store).
- Если скрипт печатает не только ASCII, пусть он сам переключит вывод на UTF-8 (`sys.stdout.reconfigure(encoding="utf-8")`), или
  вызывай его с `-X utf8`. Флаг `-I` отключает переменные `PYTHON*`, в том числе `PYTHONIOENCODING`, поэтому `python -I` без `-X utf8`
  на Windows печатает в cp1251.
- Само имя переменной в тексте SKILL.md (например, в паспорте или в объяснении для читателя) не пиши: там оно тоже будет заменено путём.

Проверка после правки навыка: в новой сессии загрузить навык и убедиться, что в загруженном тексте стоит путь к папке в кэше плагина,
а скрипт по нему запускается из папки проекта.
