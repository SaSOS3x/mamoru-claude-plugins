# Как навык вызывает свой скрипт

Этот файл читается инструментом Read как есть, поэтому переменная ниже видна в исходном виде. В SKILL.md её же Claude Code заменяет
настоящей папкой навыка при загрузке (проверено 2026-10-12 в главной сессии и у подагентов, Claude Code 2.1.294, Windows 11).

Пиши в SKILL.md так:

```
python "${CLAUDE_SKILL_DIR}/scripts/x.py" аргументы
```

- Кавычки нужны: в пути к папке плагина могут быть пробелы.
- Интерпретатор пишется явно (`python`, не голый путь к скрипту и не `python3`: на Windows `python3` бывает заглушкой Microsoft Store).
- Если скрипт печатает не только ASCII, пусть он сам переключит вывод на UTF-8 (`sys.stdout.reconfigure(encoding="utf-8")`), или
  вызывай его с `-X utf8`. Флаг `-I` отключает переменные `PYTHON*`, в том числе `PYTHONIOENCODING`, поэтому `python -I` без `-X utf8`
  на Windows печатает в cp1251.
- Заменяется только форма со знаком доллара и фигурными скобками, зато во всём SKILL.md, в том числе в паспорте и в объяснениях
  для читателя. Голое имя без них остаётся как есть (проверено: фраза «её имя CLAUDE_SKILL_DIR» в skill-forge загружается без
  изменений), поэтому в пояснениях пиши имя без `${}`.

Проверка после правки навыка. Загрузи навык в новой сессии. В загруженном тексте вместо переменной должен стоять настоящий путь к папке
навыка: тот же, что в заголовке "Base directory for this skill". Скрипт по этому пути должен запускаться из папки проекта.

## Где лежит плагин

Папку плагина определяет способ установки, поэтому угадать её из текста навыка нельзя. Проверено 2026-10-12 на Windows 11 с Claude
Code 2.1.294 и 2.1.295:

| Как плагин установлен и где запущена сессия | Откуда читается навык | Меняется ли путь с версией |
|---|---|---|
| `claude plugin install` (user scope), Claude Code в терминале | `~/.claude/plugins/cache/<маркетплейс>/<плагин>/<версия или коммит>/` | да |
| Плагин стоит на аккаунте claude.ai, сессия во вкладке Code приложения Claude | `%APPDATA%/Claude/local-agent-mode-sessions/<орг>/<пользователь>/rpm/plugin_<id>/`, приложение обновляет её при запуске | нет |
| Плагина на аккаунте нет, сессия во вкладке Code приложения Claude | та же локальная установка в `~/.claude/plugins/cache/...` | да |
| Маркетплейс-папка, плагин впервые включён и подхвачен командой `/reload-plugins` | сама папка маркетплейса | не проверялось |

Если плагин с тем же именем стоит и локально, и на аккаунте, то в проверенных случаях во вкладке Code навыки брались из копии с
аккаунта. Пока копии не было (плагин ещё не поставлен на claude.ai или приложение его ещё не скачало), та же вкладка брала
локальную установку.
`/reload-plugins` не меняет версию плагина, который уже загружен в сессию: новая версия появится только после перезапуска.
Какую версию загрузила сессия, видно по заголовку "Base directory for this skill" и по побайтному сравнению этой папки с коммитом.
