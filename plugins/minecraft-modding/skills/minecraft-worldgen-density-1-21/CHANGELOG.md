# История изменений: minecraft-worldgen-density-1-21

Что менялось в навыке, когда и почему. Новые записи добавляются в конец. Навык вырос из порта DeceasedCraft на 1.21.1. История
той работы лежит в `_port/HANDOFF.md` порта, в плагин она не входит.

## 2026-10 | Создан в порте DeceasedCraft 1.21.1
Что: обёртки density functions, чтение noise_settings, регионы TerraBlender, подгонка суши под окно высот Lost Cities, замер
высот без запуска игры её же кодом.
Почему: рельеф был слишком гористым для Lost Cities, а изменения нужно было мерить без запуска игры.

## 2026-10-12 | v33: описание с фразами-триггерами, состояние проекта вынесено
Что: в описание добавлены фразы, которые говорит пользователь. Датированное состояние порта перенесено в
`_port/reports/skills_moved_state_v33.md`.
Почему: отдельная проверка (Fable) нашла, что в описании нет фраз-триггеров, а метод смешан с состоянием проекта.

## 2026-10-12 | v34: подготовка к плагину
Что: раздел о замерах без игры обобщён, примеры порта подписаны. Вынесенный текст лежит в
`_port/reports/skills_removed_text_v34.md`.
Почему: навык уходил в плагин для всех проектов.

Почему: решение пользователя держать все навыки и инструменты в одном маркетплейсе, общем для проектов.

## 2026-10-12 | Журнал изменений на русском
Что: записи этого файла переведены на русский.
Почему: решение пользователя вести журналы изменений всех навыков по-русски, ведь записи «почему» прежде всего для него.

## 2026-10-25 | Сверка с настоящими чанками, скорость в игре, роутер в Java
Что: раздел «Measure offline»: сверка расчёта по шуму с миром (карта высот `MOTION_BLOCKING_NO_LEAVES`, ожидаемые доли совпадения,
выборка 25 чанков по 16 столбцов) и скорость в игре (высота 4,4 мс, биом 0,02 мс на столбец). Переписывание роутера в Java
вынесено в новый файл `references/router-java.md`, в SKILL.md одна строка-ссылка в разделе «Changing it».
Почему: в Space Journey сверка дважды дала ложные 47 % и 81 % (не та карта высот, лёд), 400 отдельных чанков не уложились в
10 минут; при переписывании роутера каждый пропущенный узел стоил прогона и ревью, а проверяющий ошибочно советовал убрать AT.
Отменяет часть решения разбора `skills-lab/a1-2026-10-15.md` («раздел о генераторе-наследнике и роутере не добавлен: один
проект, одна линия работы, проверено один раз»): довод «проверено один раз» отпал, способ проверен в трёх прогонах. Доводы
«один проект, одна линия работы» остаются, поэтому текст лежит в `references/`, а не в SKILL.md. Опора: дневник Space Journey
(`_project/JOURNAL-архив.md`), разбор журналов 2026-10-23 и проверка скептиков workflow wf_6513e25f-1ba. Журнал:
`skills-lab/minecraft-worldgen-density-1-21/JOURNAL.md`.
Проверено: скептиком по дневнику (4 мира с проверкой, высота 90,5-96,8 %, биом 100 %), по `accesstransformer.cfg` мода, атрибуту
InnerClasses `DensityFunctions` (`javap -v`) и AT NeoForge 21.1.250. Довод про кодек найден ревью кода, падения никто не видел.
Тест с навыком и без пока не прогонялся.
Тест 2026-10-25: только S-37, одна задача (/seedmap check, сверка карты по сиду с настоящими чанками), прежний текст : новый 4:9 и 3:9 у двух слепых судей, новый лучше (карта высот, лёд, 25 чанков по 16 столбцов, нормы), принят; S-36 (router-java.md) не тестировалась; фраза выше «тест пока не прогонялся» устарела; запись журнала навыка от 2026-10-25 (тест).
