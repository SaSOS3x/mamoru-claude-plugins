## 2026-10-25 | анализ | Зачем навык, поиск готового, решение

Задача пользователя 2026-10-23 (дословно): «просмотри общие журналы проекта и выдели из его опыта, какие навыки ещё нужно улучшить,

test-mutations, скептик (workflow wf_6513e25f-1ba) дал вердикт create.
Чего не хватило: в маркетплейсе нет общего метода «доказать, что проверка ловит». Мутации описаны только в windows-shell-dev, и
только для .cmd/.bat (grep «мутац|mutat|can't fail|always green|vacuous» по plugins/, скептик 2026-10-23).
Условия шага 3 skill-forge (проверил скептик по дневникам):

  Rhino-теста не могли провалиться, мутационный тест стал обязательным шагом проверяющего); харнесс .cmd в windows-shell-dev.
- без подсказки плохо или долго: да, с оговоркой. Саму идею мутации агенты придумали сами (2026-10-15), трудными были детали. Слепые
  проверки находили ревью ценой 1,79-2,81 млн токенов (p3-code-review, f1-1-review, f1-2-review, f1-2-rereview, f1-3-rereview-2).

  только новые FAIL, ожидаемая проверка по началу имени, образец ровно 1 раз, .bak-mutation, восстановление в finally и при старте,
  итоги в mutations/, прогон без итога повторяется раз, taskkill /T /F по тайм-ауту. Логи серий: «expected check red: yes» и
  «restored, no MUTATION left».

  независимом ответе читается как противоречие. Не внесено.
- «запись стояла в дневнике сутки»: срок не установлен; «ревью по 2,1-2,8 млн»: на деле 1,79-2,81.
