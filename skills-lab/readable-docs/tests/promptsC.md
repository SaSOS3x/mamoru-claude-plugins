# Тест C: листинг кода с опечаткой в комментарии

Вход: C.docx (собирает genC.js: `node genC.js C.docx`). Агенту файл даётся под именем sync_lab4.docx.
В документе абзац с опечаткой «праграмма», листинг C# из 10 строк (Courier New, noProof) с опечаткой «инициализацыя» в комментарии, абзац с терминами «Многопоточность», «кэш», «мьютекс» и верхний колонтитул.
Оценка: `python eval_code.py C.docx result.docx` (совпадает ли код с исходным и весь ли он без проверки) и `python eval.py C.docx result.docx --typos праграмма ...`.
Правильный итог: код побайтно тот же, «праграмма» исправлена, ложных подчёркиваний 0.

Промпт одинаковый для обеих версий, меняются только папки. `<РАБОЧАЯ>` - своя папка агента, `<НАВЫК>` - папка проверяемой версии навыка.

```
Окружение: Linux, python3 (есть lxml и spylls; пакеты ставить можно: pip install --break-system-packages ...), node с пакетом docx, pandoc, LibreOffice (soffice). Сеть до github.com есть.
Рабочая папка: <РАБОЧАЯ> (временные файлы в её подпапке tmp). Пиши только в эту папку. Читать можно эту папку и папку навыка ниже, другие папки рядом не открывай. Исходный docx не меняй.

Навык: перед работой прочитай <НАВЫК>/SKILL.md и следуй ему. В командах навыка переменную папки навыка замени на <НАВЫК>.

Задача. В рабочей папке лежит sync_lab4.docx, его собрала программа (отчёт по лабораторной о синхронизации потоков, с листингом кода из программы преподавателя). Пользователь пишет: «Word подчёркивает красным слова, которые не должны подчёркиваться: английские названия (Windows, программы, команды) и термины. Сделай так, чтобы верные слова не подчёркивались, и исправь документ.»
Исправленный документ положи в рабочую папку как result.docx.

В конце верни текстом пять пунктов: 1) ответ пользователю, как ты бы ему написал; 2) какие файлы создал; 3) какие проверки запускал и что они показали; 4) ошибки по ходу: что сорвалось, настоящая причина, как обошёл; 5) где результат отличается от просьбы пользователя или выходит за неё.
```

Для новой версии к строке «Навык» добавлялось: «Установленную копию readable-docs не используй, только этот файл.»
