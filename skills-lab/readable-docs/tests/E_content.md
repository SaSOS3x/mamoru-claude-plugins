## Цель работы

Рассчитать основные показатели выборки: среднее, дисперсию, стандартное отклонение и коэффициент вариации, и оценить, однородна ли выборка.

Задачи:
- подготовить исходные данные;
- рассчитать показатели по формулам;
- оценить однородность выборки.

## 1 Исходные данные

Время отклика сервера, мс: 46, 49, 52, 55, 60. Объём выборки n = 5.

Порядок обработки: сбор данных → проверка выбросов → расчёт показателей → выводы.

## 2 Формулы

Среднее: x̄ = (x₁ + x₂ + … + xₙ) / n   (1)
Дисперсия: D = Σ(xᵢ − x̄)² / (n − 1)   (2)
Стандартное отклонение: σ = √D   (3)
Коэффициент вариации: V = σ / x̄ · 100 %   (4)

## 3 Расчёт

Среднее: x̄ = 262 / 5 = 52,4 мс.

Дисперсия: D = 117,2 / 4 = 29,3 мс². Стандартное отклонение: σ = √29,3 ≈ 5,41 мс. Коэффициент вариации: V = 5,41 / 52,4 · 100 % ≈ 10,3 %.

## Вывод

Разброс небольшой: V ≈ 10,3 % меньше 33 %, значит выборка однородная. Логика вывода: малый V → выборка однородна → среднее 52,4 мс хорошо описывает время отклика.
